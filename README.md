# 岛不废

流体云工具箱,第一阶段实现 VPN 状态展示。

## 功能

- 自动检测 VPN 连接状态
- 显示节点所在国家/地区(国旗 + 国家名)
- 每 10 秒刷新网络延迟,超时自动提示
- 通过 Android 16 原生 Live Updates API,在 ColorOS 16 流体云上实时展示
- VPN 断开自动重置,划卡不中断后台监控

## 技术栈

- Kotlin
- Android 16(minSdk / targetSdk 36+)
- Material 3
- OkHttp
- ip-api.com(国家/IP 查询)

## 适配范围

目前仅在一加 15 / ColorOS 16 上测试,未做多厂商适配。

## 权限说明

| 权限 | 用途 |
|---|---|
| 通知权限 | 显示流体云和通知栏状态 |
| 网络访问权限 | 查询公网 IP、国家、测量延迟 |
| 前台服务权限 | 后台持续监控 VPN 状态 |
| 查看网络状态权限 | 检测 VPN 是否连接 |

## 开发状态

第一阶段(VPN 流体云)基本完成。后续计划中的模块:网络状态监控(dev1)。
