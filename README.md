# 岛不废 · 流体云工具箱

ColorOS 流体云（Android 16 原生 Live Updates / Promoted Ongoing）工具箱。所有需要"常驻可见"的信息——VPN 状态、服药提醒、自定义定时提醒——都通过系统通知通道推上**灵动岛式流体云区域**，息屏一眼可见。

> 第二个 tab 之前叫"待开发"，现在是真功能了。

## 功能

### 🔒 VPN 流体云监控
- 连接 VPN 后，流体云实时显示**节点国旗 + 延迟数字**，通知展开态还有最近测量的**三色历史条**（绿 <100ms / 橙 <300ms / 红 ≥300ms）
- 通知交互：**刷新**（立即重测）/ **暂停 / 继续** / **退出**
- 首页：圆形国旗大卡、延迟评分、**延迟趋势折线图**（最近 16 次）、断开时待机通知开关
- 常驻服务持 CPU 唤醒锁 + 电池白名单指引，灭屏充电也持续刷新
- 断开判定带 2 秒防抖，网络切换不会让流体云闪断；在途请求竞态防护

### 💊 用药提醒
- 添加药品（名称 + 服用说明 + **多个每日服药时间**），每个时间准点弹通知，通知上直接点**"已服"**
- "今日用药"清单：待服 / 已服 / 超时（60 分钟宽限期）三态，支持补服
- **月视图服药日历**：一格 = 一天，竖条 = 当天每次服药，绿=已服、红=超时未服、灰=未到/未计划，今天的格子高亮

### ⏰ 自定义提醒
- 自选大标题 / 小标题 / 时间，到点弹上流体云，每日重复
- 支持修改、删除，"知道了"一键撤下，10 分钟未处理自动收起

### 🌐 IP 诊断
- 首页入口，查看当前出口 IP 与路由，排查节点是否生效

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 16（API 36）/ ColorOS 16 及以上 |
| 权限 | 通知、**流体云（系统设置 → 通知 → 流体云）**、网络、前台服务 |
| 后台 | 建议开启自启动 + 电池"允许完全后台行为"，否则 OEM 会冻结进程 |

> 走的是谷歌原生 Live Updates 路线，所以只支持 Android 16+；ColorOS 15 及以下装不了。

## 构建

```bash
# JDK 17 + Android Studio (AGP 9.x)
./gradlew assembleDebug
```

- minSdk 36 / targetSdk 37
- 仓库无特殊签名配置，release 构建产物未签名，日常自装用 debug 包即可

## 技术要点

- 事件驱动检测 VPN（`NetworkCallback`），`StateFlow` 单一数据源驱动流体云通知与 UI
- 提醒/服药闹钟走 `AlarmManager.setAlarmClock`（精确、免 `SCHEDULE_EXACT_ALARM` 权限、Doze 下准点）
- 节点归属查询：ipwho.is → country.is → Cloudflare trace 三源 HTTPS 依次降级，失败指数退避，出口 IP 去重
- 国旗资源 16 张 WebP 共 56 KB，编译期静态映射，无反射查找
